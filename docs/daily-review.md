# OKX 每日模拟交易复盘

## 运行与范围

- 每小时 QQ 分析邮件成功交付 SMTP 后，email_notify.py 调用 recommendation_archive.py，按实际发送时间保存 0–2 个条件性方案到 data/recommendations/YYYY-MM-DD/*.json。推荐数量可能不足48；不能补造。
- 每日 UTC 15:55（北京时间23:55），.github/workflows/daily-review.yml 执行 daily_review.py，生成 data/daily_reviews/YYYY-MM-DD.md、同名JSON和 data/daily_review_state.json，并通过现有QQ SMTP Secret发信。
- GitHub定时任务可能延迟；程序按北京时间选择目标日期。手动workflow_dispatch默认dry_run=true，不发信、不持久化。
- 每笔挂单最多120分钟，未结算持仓跨日持续跟踪；从归档功能启用起积累，不能把以前未归档邮件想象成历史交易。
- 所有行情使用OKX USDT永续已收盘1m K线；数据缺口显示异常，不捏造成交。

## 两种模拟执行模型

- A 收到即挂限价：从成功发送邮件后的下一完整1m开始模拟。普通买入限价高于市场价或卖出限价低于市场价时可能立即成交，模拟使用下一分钟开盘价（若更有利）。
- B 突破回踩确认：需5m已收盘方向突破、相对前20根5m量比>=1.2、后续回踩及简化HL/LH代理确认，才激活限价委托；所有步骤须在邮件后120分钟内完成。程序代理结构并不是严格BOS/CHoCH，也不能替代人工判断。
- 单一模拟账户最多2笔并持、单笔初始风险<=0.85U、并持初始风险<=1.70U，单笔保证金<=25U、名义<=75U；初始本金100U，累计盈亏影响后续开仓。模拟不接触真实账户。

## 费率与移动止损

- 用户提供挂单maker 0.02%/边，吃单taker 0.05%/边。为跨平台保守估算，所有模拟开平均按taker 0.05%+0.05%，双边约0.10%名义成本。不计滑点、资金费、强平费；假定止损按止损价成交，真实情况可能更差。
- 盈利档位采用100倍口径下的币价变动阈值：+40%对应价格有利0.4%，+100%对应1%，+200%对应2%，+400%对应4%，+600%对应6%，+800%对应8%。杠杆不改变标的价格阈值，仅改变保证金ROI。
- 尚未达到价格有利+0.4%：保持原始止损；若触发按原始止损亏损。
- 达到+0.4%：止损改为相对实际入场价有利0.12%，即100倍口径保护+12%而非原+10%。双边都按0.05%吃单且无额外费用、精确成交时，扣费后剩余约0.02%名义盈利。
- 之后+1% → 锁+0.6%；+2% → 锁+1%；+4% → 锁+3%；+6% → 锁+5%；+8% → 全平。
- 若同1m的最高/最低价同时触及旧止损与新增里程碑，按旧止损优先；新止损同分钟可能被触及则保守认为退出。按实际合约tick向保护收益方向取整。
- 原TP1/TP2仍归档，但本动态止损模型不把它们视作自动平仓价。
- 未平仓按已收盘标记价估计浮盈亏及预计平仓费用，与已实现利润分列。

## 数据与报告

- 每封日报显示发送时间、币种方向、原限价、实际模拟成交价/平仓价、最高浮盈、最终原因及净盈亏；并给出A/B方案成交率、净盈亏、累计100U模拟权益、前日结转。
- 1m OHLC不能还原真实盘口排队、分钟内价格先后、强平或资金费；模拟并不代表真实收益或胜率。
- GitHub Actions页面选择 Daily OKX Paper Trading Review 查看运行结果。手动模拟建议使用默认dry_run=true，避免重复邮件。
